# Hallway-Nav
Creating an app to track students
We are going to use Tableau to show the map and display everything
We are going to use the A star algorithm to find the shortest route to everything. 
We are converting the png files of each floor and importing them into CBI studios.
Get the map coordinates by filling the hallways with point and export them to React in CSV format. 
Barcode scanner works with the raspberry pi scanner as provided by Dr. Miller
Map buttons are functional and click to different floor level plans.
